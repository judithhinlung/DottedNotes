# BANA Braille Music Reference

This document is a working reference for the braille music symbols used by
DottedNotes, as defined by the Braille Authority of North America (BANA).

## Source

*New International Manual of Braille Music Notation* (BANA, 1997)
and the 2015 BANA revision.

## Note Values

| Symbol | Meaning |
|--------|---------|
| ⠽     | C whole note |
| ⠵     | C half note |
| ⠹     | C quarter note |
| ⠙     | C eighth note |
| ⠑     | C sixteenth note |
| ⠋     | C thirty-second note |

## Octave Marks

Octave marks precede the note and apply until a new octave mark appears.

| Symbol | Octave |
|--------|--------|
| ⠈⠈   | 1 (sub-contra) |
| ⠈     | 2 (contra) |
| ⠘     | 3 (great) |
| ⠸     | 4 (small / middle C octave) |
| ⠐     | 5 (one-line) |
| ⠨     | 6 (two-line) |
| ⠰     | 7 (three-line) |
| ⠠     | 8 (four-line) |

## Rests

| Symbol | Value |
|--------|-------|
| ⠍     | Whole rest |
| ⠥     | Half rest |
| ⠧     | Quarter rest |
| ⠭     | Eighth rest |
| ⠵     | Sixteenth rest |

## Key Signatures

Key signatures appear at the beginning of a line using the number of sharps
or flats preceded by the appropriate prefix.

## Time Signatures

Time signatures use braille number cells preceded by ⠼.
